=== Redis Streams output plugin

include::{include_path}/plugin_header.asciidoc[]

==== Description

This plugin sends events to Redis Streams using the `XADD` command. Redis Streams, introduced in Redis 5.0, provide a powerful append-only data structure for message queuing and event sourcing.

Key features include:

* **Stream Partitioning**: Distribute events across multiple streams using different strategies
* **Batching Support**: Batch multiple events for better performance  
* **Stream Trimming**: Automatic stream length management
* **SSL Support**: Full SSL/TLS configuration support
* **Connection Management**: Automatic reconnection and multiple host support

[id="plugins-{type}s-{plugin}-stream"]
===== `stream` 

  * This is a required setting.
  * Value type is <<string,string>>
  * There is no default value for this setting.

The name of the Redis stream. Dynamic names are valid here, for example `logstash-%{type}`.

[id="plugins-{type}s-{plugin}-host"]
===== `host` 

  * Value type is <<array,array>>
  * Default value is `["127.0.0.1"]`

The hostname(s) of your Redis server(s). Ports may be specified on any hostname, which will override the global port config.

[id="plugins-{type}s-{plugin}-enable_partitioning"]
===== `enable_partitioning` 

  * Value type is <<boolean,boolean>>
  * Default value is `false`

Enable stream partitioning to distribute events across multiple streams.

[id="plugins-{type}s-{plugin}-partition_strategy"]
===== `partition_strategy` 

  * Value type is <<string,string>>
  * Default value is `"random"`
  * Valid values are `"random"`, `"hash"`, `"time_based"`

Partitioning strategy when partitioning is enabled:

* `"random"`: Events are randomly distributed across partitions
* `"hash"`: Events are distributed based on hash of a field value  
* `"time_based"`: Streams are named with time-based suffixes

[id="plugins-{type}s-{plugin}-partition_count"]
===== `partition_count` 

  * Value type is <<number,number>>
  * Default value is `1`

Number of stream partitions to create when using `"random"` or `"hash"` partitioning strategies.

[id="plugins-{type}s-{plugin}-maxlen"]
===== `maxlen` 

  * Value type is <<number,number>>
  * Default value is `0`

Maximum length of each stream. When a stream reaches this length, Redis will automatically trim it. Set to 0 to disable trimming.
